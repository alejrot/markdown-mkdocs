# `children`

## Resumen

Esta opción incluye solamente los archivos con menos jerarquía
que el documento actual y que están incluidos en su misma sección o carpeta.


## Uso

En el archivo donde se necesita el índice escribir:

`{{` `pagetree(children)` `}}`

## Resultado

{{ pagetree(children) }}
